# GLAIRE Haircare Studio

Сайт студии красоты и волос GLAIRE в Перми по адресу: г. Пермь, ул. Пионерская, 15, студия 2F. Основная страница находится в `index.html`, админка для локального редактирования контента находится в `admin-panel.js`.

## Что загружать на хостинг

- `index.html` — основной сайт.
- `admin-panel.js` — локальная админ-панель, открывается через `?admin=1`.
- `assets/` — локальные шрифты и резервные оптимизированные фотографии студии. Актуальные галереи, видео, QR и логотипы подключаются через Cloudinary.
- `CNAME` — домен `glaire.ru` для GitHub Pages.
- `favicon.ico` — иконка вкладки браузера.
- `.nojekyll` — отключает обработку Jekyll на GitHub Pages.
- `.htaccess` — настройки HTTPS, кеша и сжатия для SpaceWeb или другого Apache-хостинга.
- `robots.txt`, `sitemap.xml`, `site.webmanifest`, `browserconfig.xml` — файлы для индексации, установки и браузерных иконок.

## Где менять контент

Большинство текстов, ссылок, фото, QR и видео лежит в объекте `CONFIG_DEFAULT` внутри `index.html`.
Массивы `STUDIO_PHOTOS` и `MASTER_PHOTOS` задают порядок 12 фотографий помещения и 14 фотографий мастера. Рамки галерей работ, студии, мастера и акций подстраиваются под пропорции выбранного снимка, включая горизонтальные фотографии. Снимки отображаются целиком, без кадрирования и увеличения при наведении. HEIC автоматически преобразуется Cloudinary в формат, поддерживаемый браузером.

Изображения получают варианты `srcset` от 160 до 1280 px с качеством `q_auto:good`. Браузер выбирает размер под фактическую ширину блока и плотность экрана. Вся галерея заранее не скачивается: загружается выбранный снимок, а нижние изображения используют отложенную загрузку. Известные размеры резервируют место до загрузки, у новых фотографий пропорции определяются автоматически.

Для первого снимка студии подготовлены пять локальных WebP-копий шириной 320, 480, 640, 960 и 1280 px с качеством 86. Они находятся в `assets/images/` и ускоряют первый экран за счёт доставки с собственного хостинга. Исходная Cloudinary-ссылка остаётся в конфигурации; при недоступности локальной копии используется CDN.

Интерактивная Яндекс Карта подключается только по кнопке «Показать карту». Видеолента не загружает ролики вне экрана; у соседних карточек подготавливаются обложки, декодируется только активный ролик. Для пользователей с уменьшением движения автопрокрутка работ отключена.

В блоке акций пять карточек: первые три сохранены, четвёртая и пятая добавлены. Лента прокручивается в сторону на любом размере экрана.

В галерее работ пять существующих работ и пять новых заготовок, у каждой новой — два места под фотографии. Для постоянного заполнения меняй `newWork1Title`, `newWork1Note`, `newWork1Photo1`, `newWork1Photo2` и аналогичные ключи до `newWork5` в `CONFIG_DEFAULT`. Эти же поля доступны в локальной админке.
Если открыть сайт с параметром `?admin=1`, появится локальная админка. Она сохраняет изменения только в браузере через `localStorage`.

SEO-данные лежат в нескольких местах и должны совпадать между собой: `<head>` в `index.html`, блок Schema.org `application/ld+json`, видимый блок контактов, `sitemap.xml` и `site.webmanifest`. Единый адрес для сайта: г. Пермь, ул. Пионерская, 15, студия 2F. Основные услуги: парикмахер, колорист, окрашивание, стрижки, уход, реконструкции, модификации и консультация перед записью.

## Важно

Для публикации постоянных изменений на GitHub или хостинге нужно менять файлы проекта и заново загружать их. Изменения из локальной админки видны только на том устройстве, где они были сохранены.

Если сайт выкладывается на GitHub Pages, файл `.htaccess` просто не используется. На SpaceWeb его нужно загружать вместе с остальными публичными файлами в корень сайта.

Два файла `index — бэкап … совершенный.html` хранятся в GitHub как резервные исходники, но не публикуются в `public_html`. Служебные файлы macOS (`.DS_Store`), временные профили браузера и архивы переноса в репозиторий и на хостинг не загружаются.

Ошибочные прежние дубли `gitignore`, `nojekyll` и `htaccess` без начальной точки удалены из актуальной ветки GitHub. Рабочие служебные пути имеют правильные имена `.gitignore`, `.nojekyll` и `.htaccess`; старые варианты остаются доступными только в истории репозитория и резервном архиве.
